# Antigravity Markdown Editor

Antigravity is a highly-performant, minimalist macOS Markdown editor designed to provide a seamless, Typora-like "What You See Is What You Get" (WYSIWYG) editing experience.

## ✨ Features
- **Real-time Rendering:** Instantly formats Markdown syntax into beautiful typography.
- **Minimalist macOS UI:** A native, distraction-free interface that blends with your system.
- **Intelligent Formatting:** Seamless cursor management and Markdown parsing.
- **Export Options:** Easily export your documents to PDF and HTML formats.

## 🛠️ Technology Stack
- **Electron:** Cross-platform desktop application framework.
- **Vite:** Next-generation frontend tooling for rapid development.
- **Vanilla JavaScript & CSS:** Lightweight and performant logic with rich modern styling.

## 🚀 Getting Started

### Prerequisites
- Node.js installed

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/tonqqsd/Antigravity.git
   ```
2. Navigate into the project directory:
   ```bash
   cd antigravity
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To launch the app for development:
```bash
npm run dev
```

### Building for Production
To package the app for macOS:
```bash
npm run build
```
